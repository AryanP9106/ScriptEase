# ScriptEase

ScriptEase converts typed text, DOCX files, and text-based PDFs into a PDF rendered from your own handwriting.

## Quick start

1. Install Python dependencies: `python -m pip install -r requirements.txt`
2. Start the application: `streamlit run main.py`
3. Download the labelled writing sheets, print them at 100%, and fill every box.
4. Upload the five scanned sheets to build your personal glyph library.
5. Upload a typed TXT, DOCX, or text-based PDF (or paste text), then download the handwritten PDF.

Run the checks with `python -m unittest discover -s tests`.
